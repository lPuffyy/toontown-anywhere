# Lawbot HQ cog suit parts quests

_Tiers 18-31. [Back to the quest guide](Home)_

## Tier 18

Each time you ask for a task you are offered up to 3 to pick from.

**Rewards you must earn to finish this tier (in this order):**

1. Lawbot Upper Left Leg Part

### Set task chains
_Each of these ends in one particular reward._

#### Ends with: Lawbot Upper Left Leg Part

1. `Visit` **Visit Professor Flake** (get it from any Toon that offers tasks (Toon HQ officers do); Precipitation Foundation, Polar Place (The Brrrgh))
2. `Recover` **Recover an External Temperature Sensor from The Cogs on Silly Street** (get it from **Professor Flake** (Precipitation Foundation, Polar Place (The Brrrgh)); hand in to **Professor Flake** (Precipitation Foundation, Polar Place (The Brrrgh)); **Reward: Lawbot Upper Left Leg Part**)

1. _Continues at step 11001 (listed above)._
