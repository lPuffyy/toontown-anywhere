# Bossbot HQ cog suit parts quests

_Tiers 32-48. [Back to the quest guide](Home)_

## Tier 32

Each time you ask for a task you are offered up to 3 to pick from.

**Rewards you must earn to finish this tier (in this order):**

1. Bossbot Upper Left Leg Part

### Set task chains
_Each of these ends in one particular reward._

#### Ends with: Bossbot Upper Left Leg Part

1. `Visit` **Visit Shep Ahoy** (get it from any Toon that offers tasks (Toon HQ officers do); All For Nautical, Seaweed Street (Dock Harbor))
2. `Wanted` **Defeat a Flunky** (get it from **Shep Ahoy** (All For Nautical, Seaweed Street (Dock Harbor)); hand in to **Shep Ahoy** (All For Nautical, Seaweed Street (Dock Harbor)); **Reward: Bossbot Upper Left Leg Part**)

1. _Continues at step 12001 (listed above)._
